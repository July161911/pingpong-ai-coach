# iTT 产品功能架构

## 主流程

```text
本地注册/登录
      │
      ├── 训练首页 ──▶ 拍摄或选择视频
      │                         │
      │                         ▼
      ├── AI 教练 ──▶ 视频分析服务 ──▶ 动作报告 ──▶ 推荐训练计划
      │                                      └────▶ 训练记录
      ├── 训练记录
      ├── 发现
      └── 用户资料 / 设置 / 训练计划
```

## 当前实现状态

| 能力 | 当前实现 | 下一阶段 |
|---|---|---|
| 视频上传与报告 | 拍摄/相册、预览、演示 AI 报告 | 接入姿态估计与乒乓球评分服务 |
| 推荐训练计划 | 每份报告自动创建本地推荐计划 | 根据长期趋势调整负荷 |
| 自建训练计划 | 本地创建、持久化、完成状态 | 日历、提醒和训练组计时 |
| 训练记录 | 保存本次报告并展示历史记录 | 趋势统计与筛选 |
| 发现 | 专项训练、教练精选和训练提示 | 接入正式内容数据源 |
| 主题 | 白天、黑夜、跟随系统 | 完善所有图表的深色配色 |
| 账号 | 手机/邮箱本地直接登录注册 | 可选云同步和正式身份验证 |

## 数据边界

- 当前账号、主题和训练计划保存在设备本地。
- 视频 AI 仍是可替换的演示服务，不应作为专业技术结论。
- 应用不再连接或读取任何外部动作传感器。
